# Илмисино (Ilmisino)

Ёрдамчии бемаҳдуди ҳушманд барои довталабони имтиҳони маркази миллии тестӣ (ММТ).

---

## Танзими тағйирёбандаҳо дар Render (Environment Variables on Render)

Ҳангоми ҷойгиркунии барнома (Deployment) дар платформаи **Render** (дар бахши *Web Service* -> *Environment*):

1. **`GEMINI_API_KEY`**:
   - Калиди Gemini API-ро аз [Google AI Studio](https://aistudio.google.com/) нусхабардорӣ карда, дар бахши Environment Variables-и Render ҳамчун қимати `GEMINI_API_KEY` ворид кунед.
   - **Амният**: Калиди мазкур танҳо дар тарафи сервер (`server.ts`) нигоҳ дошта шуда, ҳеҷ гоҳ ба браузер ё бандили фронтенд интиқол намеёбад.

2. **`TELEGRAM_BOT_TOKEN`** (Ихтиёрӣ барои қабули гузоришҳои хатогӣ):
   - Боти нав дар [@BotFather](https://t.me/BotFather) эҷод кунед ва токени гирифтаатонро дар ин ҷо сабт намоед.

3. **`TELEGRAM_CHAT_ID`** (Ихтиёрӣ):
   - ID-и чати худ ё гурӯҳро (ки аз ботҳо ба монанди [@userinfobot](https://t.me/userinfobot) дастрас кардан мумкин аст) ворид кунед. Ҳамаи гузоришҳои донишҷӯён аз тугмаи «🚩 Хато ёфтам» ба таври худкор ба ин чат фиристода мешаванд.

4. **`NODE_ENV`**:
   - Барои ҳолати истеҳсолӣ қимати `production` гузоред.
